# Installation

## Method 1: Roblox Marketplace (Recommended)

## Download from the Roblox Marketplace

**Go to Roblox Marketplace**

**Click "Get Module" to obtain the ModuleScript**

**Insert it into ReplicatedStorage or another convenient folder**
